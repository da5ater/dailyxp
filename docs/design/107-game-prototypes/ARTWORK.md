# Quest cartridge artwork

The original low-polygon fantasy scene was generated with OpenAI image generation on 2026-10-21 for DailyXP. No franchise characters, logos, interface text or third-party game screenshot was used. The source PNG is kingdom-ps1.png; the renderer bundles the same bytes locally and performs no image requests.

Art direction: a 1997-style low-polygon fantasy adventure, copper-cloaked traveler at lower left, reclaimed stone kingdom across a chasm, winding path and bridge, three simple towers and a mustard flag. Faceted geometry, low-resolution texture character, ordered dithering, angular mountains, deep ultramarine twilight and warm amber horizon. Palette references were ink navy #111429, ultramarine #303BA1, slate #58648E, moss #48634D, parchment #E5DEBC and amber #FFBE57. No text, logos, HUD, scanlines, neon vaporwave, photorealism or modern glossy rendering.

The scene is decorative. Domain progress is shown separately from this static illustration. Press Start 2P is bundled under the existing fonts/OFL.txt license; Inter and IBM Plex Mono carry their license files beside the renderer fonts.
