# Domain Docs

DailyXP uses a single domain context.

Before exploring or changing the product, read:

- `CONTEXT.md` for canonical product language.
- Applicable decisions under `docs/adr/`.

Use glossary terms in issues, specifications, code, tests, and reviews. Surface
any proposed behavior that contradicts an ADR instead of silently overriding
it. Create ADRs only for consequential, hard-to-reverse trade-offs.
