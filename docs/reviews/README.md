# Illustrated click guides

Each implementation gets a short HTML guide with actual Before / During / After pictures for its user-visible changes. Before uses the last release, or last installed version if no tagged release exists. State the exact previous problem and name the controls to click in the actual application. Keep typing minimal.

These pages guide real app use. They do not contain a duplicate app, input forms, a control bridge, blast-radius sections or test reports. Open the HTML in the Codex side panel. Detailed verification remains in issue/PR evidence.
