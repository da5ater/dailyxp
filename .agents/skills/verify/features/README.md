# DailyXP verification map

Launch a fresh isolated host with the parent skill, then run doctor. Never drive the personal installed plugin. Each mutation must settle before the next command. Read back status and inspect retained state after cleanup.

- [Panel and navigation](navigation.md): open/close, Play/Journey/World, reduced motion.
- [Focused sessions](sessions.md): start, pause, resume, finish and status.
- [Planning-day lifecycle](planning-day.md): idempotent day advancement and persistence.

The driver copies the current checkout into a private headless Wayland host. QtTest pointer and keyboard input stays within that host. Production IPC commands and control input are separate evidence paths. New acceptance criteria require updating these recipes.
