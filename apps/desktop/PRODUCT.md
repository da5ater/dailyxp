# DailyXP desktop core

<!-- impeccable:product-schema 1 -->

## Platform

web

## Operating context

A standalone Electron desktop application for Linux, first integrated with Omarchy. The renderer uses web technologies. Other distributions should need only the packaged desktop application, not Quickshell. Windows, macOS and mobile are future expansion considerations, not claimed supported clients.

## Users and purpose

Mohamed wants a less cluttered daily tool for intentional work, Habits, Goals, progress and private Recovery. One meaningful next action should dominate the daily experience. This record follows his explicit issue #107 request and the repository's domain glossary and V1 PRD.

## Capabilities and constraints

The application owns its local journal and progress. A compact Omarchy companion reads safe status and issues limited Session and window commands. Integrations do not own progress. Preserve existing earned progress, offline operation, domain terminology and Recovery privacy. Social data must never be fabricated.

## Approved direction

On 2026-10-21 Mohamed selected A, Quest cartridge, the dark PS1 adventure with castle artwork. This is the single production design. The app does not retain the rejected design selector. Native mobile clients and other operating systems require later work.
