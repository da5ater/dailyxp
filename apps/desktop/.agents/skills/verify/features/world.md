# World

World maps each active Goal to a Province. Milestone completion takes precedence for fill; without Milestones, completed commitments or positive finished linked Sessions count. Achieved provinces stay reclaimed. Momentum and its cause come from the progression projection. No competition fixtures belong here.

Run the default empty-profile journey: open World before creating anything, create a Goal and two Milestones through Plan, complete one, then assert the Province is 50% with one built landmark. Capture the rendered state.

Run the time-dependent edge journey separately:

```sh
node apps/desktop/scripts/verify-world.cjs /tmp/dailyxp-world-UNIQUE
node apps/desktop/scripts/verify-world.cjs /tmp/dailyxp-world-milestone-UNIQUE milestone
```

It prepares only its disposable profile using production Core commands and an owned clock to reach eight elapsed eligible days. It launches real Electron on the private display, proves Hollow King affects only unfinished provinces, checks 699px layout, completes a real Habit through Play and verifies the resting marker immediately clears without XP loss. The second command repeats the condition and completes a real Milestone through Plan instead of the Habit, proving its canonical event date contributes to activity and clears Hollow King. It also closes/reopens an unfinished private form and proves fields are erased and entry confirmation returns. It also sends SIGTERM to the actual main process and asserts graceful exit code 0. This clock-prepared journey supplements the empty-state journey; it does not replace it. `DAILYXP_VERIFY_EXECUTABLE` selects a packaged executable.
