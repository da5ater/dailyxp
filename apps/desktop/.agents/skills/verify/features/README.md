# Core application feature map

- [Daily work and Sessions](sessions.md). Empty-state Task creation, selection, start, companion control, finish and replay.
- [Planning and Routines](planning.md). Goals, Milestones, Tasks and dated Routine work.
- [Habits and Journey](progress.md). Habit completion, permanent XP and explainable history.
- [Private Recovery](recovery.md). Protected entry and separate private tracks.
- [Settings and integrations](settings-integrations.md). Preferences, import/export and compact desktop clients.

The default `run` journey covers Sessions, Habit XP, Routine entry, the selected Quest design, private Recovery, Goals/Milestones, save failure, keyboard focus, constrained layout, and reduced motion. Feature entries describe additional routes that must be exercised when changed. A map entry is not a claim that every route is already automated.
